# CodeMirror branding

Unmodified original: https://raw.githubusercontent.com/codemirror/website/main/site/style/logo.svg

The official CodeMirror website uses this logo. `icon.png` (256×256) and `logo.png`
(640×640) are transparent PNG rasterizations of that SVG, with no redesign or added
text. The originals and MIT notice are retained here. Run
`node scripts/render_branding.mjs` from the repository root to regenerate them
using installed Chrome and the frontend Playwright development dependency.
